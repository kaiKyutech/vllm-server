# RTX 3090で試す

Linux / WSL2のx86_64、Python 3.12、GPUを認識するNVIDIAドライバが必要。
WindowsネイティブではなくWSL2またはLinuxで実行する。
RTX 3090実機は未検証。以下は24GBで最初の動作を確認するための設定例。
現在の固定環境はvLLM 0.19.1 / PyTorch 2.10.0+cu129。

## 取得と環境構築

```bash
git clone https://github.com/kaiKyutech/vllm-server.git
cd vllm-server
python3.12 --version
nvidia-smi
./setup/install.sh
./scripts/doctor.sh
```

モデル・仮想環境はGitHubには含まれない。モデルは以下から使うものだけを取得する。
ディスクには環境約11GiBに加えて各モデル約18～20GBとキャッシュの空きが必要。

## Ministral 3 8B BF16

```bash
./scripts/download.sh mistralai/Ministral-3-8B-Instruct-2512-BF16 \
  --revision f6fae9795746f63c9be8344932f01275f3c63734
cp configs/ministral-3-8b.sample.yaml configs/ministral-3-8b.yaml
./scripts/start.sh configs/ministral-3-8b.yaml \
  --max-model-len 8192 --max-num-seqs 1 \
  --max-num-batched-tokens 2048 --gpu-memory-utilization 0.90
```

APIのモデル名は `ministral-3-8b`。
YAMLの `config-format: mistral` と `load-format: safetensors` を維持する。
A100で確認済みの読み込み設定だが、3090のメモリに収まることの保証ではない。

## Qwen3.5 9B BF16

前のサーバーをCtrl+Cで終了してから実行する。

```bash
./scripts/download.sh Qwen/Qwen3.5-9B
cp configs/server.sample.yaml configs/server.yaml
./scripts/start.sh configs/server.yaml \
  --max-model-len 8192 --max-num-seqs 1 \
  --max-num-batched-tokens 2048 --gpu-memory-utilization 0.90
```

APIのモデル名は `qwen35-9b`。
各見本は変更せず、`.sample`を外したコピーを編集する。
コピー先が既にある場合、`cp`で上書きする前に保存する。

## API確認

別ターミナルから実行する。Qwenの場合はmodelを `qwen35-9b` に変更する。

```bash
curl http://127.0.0.1:8000/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"ministral-3-8b","messages":[{"role":"user","content":"日本語で挨拶してください。"}],"max_tokens":128,"stream":false}'
```

`.env`でAPIキーを設定した場合はAuthorizationヘッダーも付ける。
初回コンパイルは数分かかる場合がある。APIが起動するまで待つ。

## 長文・並列数を増やす

起動確認後、CLIで指定した値をコピー先YAMLに保存すれば、次回は例えば
`./scripts/start.sh configs/ministral-3-8b.yaml` で起動できる。
20K入力を使う場合は入力と出力の合計に合わせて `max-model-len` を増やし、
まず同時1件で確認してから並列数を増やす。A100用の上限32をそのまま使う必要はない。

メモリ不足なら他のGPU処理、コンテキスト長、バッチ数を確認する。
CUDA graph用メモリが問題なら `--enforce-eager` で切り分けできるが、速度は別途測る。
BF16で必要な長文・並列数を確保できない場合は、小さいモデルや対応量子化を検討する。
4Bモデル・量子化モデルの実機確認は今後の作業であり、このリポジトリでは検証済みとしない。

各マシンで調整した `configs/*.yaml`（`.sample.yaml`以外）、`.env`、モデル、キャッシュはGit対象外。
更新は `git pull --ff-only`。依存関係が変わった場合は `./setup/install.sh` を再実行する。
